# README branding

Use the shared, fixed-ground logo in repository headers:

```html
<p align="center">
  <a href="https://vidra.yosef.app">
    <img src="https://raw.githubusercontent.com/yegamble/vidra-branding/main/assets/readme/logo.svg" width="268" alt="Vidra">
  </a>
</p>
```

For a full-width launch banner, use `assets/readme/banner.svg`. Do not apply inversion filters or OS appearance rules. Keep technical repository descriptions accurate; the launch headline is marketing copy, not a replacement for a repository’s purpose.
